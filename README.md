# Copilot Studio 입문 랩

Microsoft Copilot Studio를 처음 쓰는 사람을 위한 **1일 핸즈온 교안**입니다. 에이전트를 만들고, 지식을 붙이고, 토픽으로 대화를 정하고, 커넥터·에이전트 흐름·MCP로 바깥과 잇는 데까지 갑니다.

배포: `https://jm-2ktech.github.io/cs_lab/`

## 무엇을 다루나

| 랩 | 분 | 내용 |
|---|---|---|
| Lab 1 | 35 | Agent Builder로 첫 에이전트 — 지침과 가드레일 |
| Lab 2 | 40 | 지식 기반 챗봇 — 오케스트레이터 · 지식 4종 · 근거 검증 |

| Lab 5 | 40 | 커넥터 — 읽고, 계산하고, 쓴다 |

**핸즈온 265분.** 표에 적힌 시간은 손을 움직이는 시간만입니다. 랩마다 시작 전 개념 설명과 마무리 정리로 10분 정도가 더 붙습니다.

이 밖에 [부록 모음](docs/appendix/)(RAG·토큰·문서 구조, 모델 비교, 채널 게시 등)과 [용어집](docs/glossary.md)이 있습니다.

## 이 교안의 특징

**전 스텝이 실측입니다.** 246컷의 스크린샷이 전부 실제 화면이고, 랩마다 초안의 전제가 최소 한 번씩 뒤집혔습니다. 트리거 문구 목록이 없다는 것, 값이 칸을 밀려 들어간다는 것, MCP는 카탈로그가 아니라 주소로 등록한다는 것 — 전부 클릭해 봐야 나온 것들입니다.

**실패를 먼저 보여줍니다.** 설명을 뭉개면 토픽이 안 불리고, 커넥터로 쓰면 값이 어긋나고, 흐름으로 바꾸면 제자리에 들어갑니다. 되는 화면만 보여주면 왜 그렇게 하는지가 남지 않습니다.

**하루가 한 질문으로 이어집니다.** 어디까지 맡기고 어디부터 정하는가. 랩 여섯 개가 그 질문에 각각 답합니다.

## 준비물

- Microsoft 365 테넌트와 라이선스가 부여된 계정
- **Copilot Studio Authors** 권한
- Power Platform 환경의 **Environment Maker** 권한
- **Azure Subscription + Power Platform PAYG** — 에이전트 게시에 필요합니다

> 트라이얼 라이선스는 만들기와 테스트는 되지만 **게시가 막힙니다.** Lab 2와 Lab 6이 게시를 요구하므로 미리 확인해야 합니다.
> Default 환경은 피하고 별도 환경을 받는 편이 좋습니다.

## 저작 규칙

- **랩 1개 = 1페이지.** 서브유닛으로 쪼개지 않고 평평한 번호 시퀀스만 씁니다.
- **「예상 시간」은 순수 핸즈온 시간입니다.** 개념 설명과 마무리 피드백은 포함하지 않습니다.
- **스텝 하나당 1.5분**으로 잡습니다. 표기 시간 ÷ 1.5 가 필요한 스텝 수입니다. 랩 6개가 실측에서 1.43~1.60분에 들어왔습니다.
- **본문은 중립 표기.** 고객사 고유 소재는 오버레이로 분리합니다. 현재 교체 지점은 `docs/lab5.md` 「준비」 절의 지원기준 표 한 곳뿐입니다.
- **절을 여러 개로 쪼갤 때는 `{: start="N" }`** 을 붙입니다. 테마가 CSS 카운터로 번호를 그려서 이게 없으면 절마다 1부터 다시 찍힙니다.
