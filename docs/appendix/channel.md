# 채널로 내보내기 — M365 Copilot · Teams 📣

{: .time }
약 20분. **랩 진행에 필요하지 않습니다.** [Lab 2](../lab2.html)에서 게시까지 마쳤다면 이어서 할 수 있습니다.

> **이 부록에서 하는 것**: 만든 에이전트를 **채널**에 올려 스튜디오 밖에서 열어 봅니다.
> **완성 신호**: 테스트 창이 아닌 곳에서 내 에이전트와 대화한다. 그리고 [Lab 1](../lab1.html) 7번에서 등록한 **추천 프롬프트가 그제야 보인다.**

---

## 왜 이걸 하나

**하루 종일 테스트 창 안에서만 놀았습니다.** [Lab 2](../lab2.html)에서 게시를 눌렀지만 그다음이 없었습니다. 게시는 "저장한 것을 반영한다"였지, "남이 쓸 수 있게 한다"가 아니었습니다.

한 가지가 더 걸려 있습니다. [Lab 1](../lab1.html) 7번에서 **추천 프롬프트** 두 개를 등록했는데, [Lab 2](../lab2.html) 8번에서 테스트 패널에는 나오지 않았습니다. 이유는 그 자리의 설명에 적혀 있었습니다 — 「Teams 및 Microsoft 365 채널에 대한 대화를 시작하는 방법을 제안합니다」. **채널에 올라간 뒤에만 보입니다.**

## 단계

{: .note }
**이 절은 아직 작성되지 않았습니다.** 화면 실측과 참조 자료 정리가 끝나면 스텝으로 채웁니다.

아래 뼈대까지 정해져 있습니다.

| | 무엇을 |
|---|---|
| ① | **채널** 탭을 열어 무엇을 고를 수 있는지 본다 |
| ② | **Microsoft 365 Copilot** 채널을 켜고 Copilot에서 내 에이전트를 연다 |
| ③ | **Teams** 채널을 켜고 Teams에서 같은 에이전트를 연다 |
| ④ | 두 화면에서 **추천 프롬프트**가 카드로 뜨는 것을 확인한다 |
| ⑤ | 옆자리와 링크를 주고받아 **상대 화면에서** 열어 본다 |
