# 부록 🧰

본문에 넣지 않은 실습과 읽을거리를 모았습니다. 시간이 남을 때, 또는 나중에 혼자 해볼 몫입니다. 순서에 상관없이 골라 하면 됩니다.

### 제품을 더 만져 본다

| 부록 | 분 | 무엇을 보나 | 이어지는 부록 |
|---|---|---|---|
| [이벤트 트리거로 신청 받기](./trigger.html) | 25 | Forms 제출을 트리거로 받아, 흐름에서 응답 내용을 넘기고 목록에 기록한다 | |
| [경조 신청 사유별 조회 흐름](./sp-query-flow.html) | 20 | 목록을 사유로 걸러 읽는 흐름을 만들어 조회 도구 대신 에이전트에 연결한다 | [이벤트 트리거로 신청 받기](./trigger.html) |

### 왜 그런지 이해한다

조작보다 **판단**을 다룹니다. 다른 도구로 옮겨 가도 남는 이야기라, 수준이 높은 차수에서 값이 큽니다.

| 부록 | 분 | 무엇을 보나 | 이어지는 부록 |
|---|---|---|---|
| [에이전트 안에서 일어나는 일](./inside-the-agent.html) | 5+10+10 | RAG·인덱싱 · 토큰과 비용 · 문서가 답을 정한다 | [읽어 오는 양](./read-volume.html) |
| [지침을 어떻게 쓰는가 — 마크다운과 구조](./instructions-markdown.html) | 15 | 지침이 왜 그런 모양인가. 근거가 있는 말과 없는 말 | [모델](./model.html) |
| [모델을 바꾸면 같은 지침이 다르게 지켜진다](./model.html) | 20 | 지침은 같은데 답이 갈린다. 근거 표시가 거짓인 경우 | [지침 작성](./instructions-markdown.html) |
| [읽어 오는 양 — 1,000행짜리 표를 붙이면](./read-volume.html) | 20 | 전부 오지 않는다. 그런데 그 사실이 안 드러난다 | [에이전트 안에서 일어나는 일](./inside-the-agent.html) 2부 |

{: .note }
**네 부록은 Copilot Studio를 안 쓰게 되더라도 남습니다.** 근거를 어디서 찾을지, 지침을 어떻게 쓸지, 모델이 무엇을 정하는지는 도구가 바뀌어도 같은 질문입니다.

{: .note }
**「에이전트 안에서 일어나는 일」은 세 부분이 따로 놉니다.** 1부(RAG·인덱싱)는 **인덱싱을 기다리는 동안 읽는 분량**이라 추가 시간이 들지 않습니다. 2부(토큰·비용)는 토크나이저를 직접 돌려 보는 15분 실습이고, 3부(문서 준비)는 10분이면 읽습니다. 셋 중 필요한 부분만 골라 써도 됩니다.

{: .warning }
**「지침을 어떻게 쓰는가」·「모델을 바꾸면」·「읽어 오는 양」은 끝나고 반드시 되돌려 놓으세요.** 모델과 지침을 바꾼 채로 두면 이후 테스트가 다른 조건에서 돌아갑니다. 되돌릴 지침은 시작 전에 복사해 둡니다.
