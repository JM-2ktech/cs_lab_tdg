{: .time }
약 20분.

> **이 부록에서 하는 것**: 경조신청 목록을 사유로 걸러 읽는 에이전트 흐름을 만들고, 조회 도구 대신 에이전트에 연결합니다.
>
> **완성 신호**: 사유를 바꿔 물으면 그 사유로 기록된 신청만 답에 나온다

---

## 준비

- `경조신청_HGD` 목록과 `경조 신청 조회` 도구가 있는 복리후생 안내 도우미에서 합니다. 목록에 기록이 몇 건 있어야 결과를 볼 수 있습니다.

---

## 단계 ① 조회 흐름

1. 상단 **도구** 탭에서 **+ 도구 추가**를 누르고, 위쪽 **새로 만들기**에서 **에이전트 흐름**을 고릅니다.

    툴바의 **초안 저장**을 먼저 누르고, 좌측 상단 이름을 아래로 바꿉니다. `HGD` 대신 본인 이니셜을 넣습니다.

    ```
    경조 신청 사유별 조회 HGD
    ```

    {: .warning }
    **이름부터 바꾸면 저장되지 않습니다.**

2. 캔버스의 **manual** 노드를 누르고, **매개 변수** 탭에서 **+ 입력 추가**를 누릅니다.

    형식을 고르고 이름과 설명을 입력합니다.

    | 형식 | 이름 | 설명 |
    |---|---|---|
    | 텍스트 | `사유` | `조회할 경조 사유를 입력하세요` |

3. 트리거와 **Respond to the agent** 사이의 **+** 를 누릅니다.

    **작업 추가**의 **커넥터별**에서 **SharePoint**를 누르고 **항목 가져오기**를 고릅니다.

    매개 변수 두 칸을 채웁니다.

    | 매개 변수 | 값 |
    |---|---|
    | 사이트 주소 | `경조신청_HGD` 목록이 있는 SharePoint 사이트 |
    | 목록 이름 | `경조신청_HGD` |

4. **고급 매개 변수** 목록을 펼치고 **필터 쿼리**와 **최대 개수**를 체크합니다.

    **필터 쿼리**에 아래를 입력합니다.

    ```
    사유 eq ''
    ```

    작은따옴표 사이에 커서를 두고 `/` 를 입력한 뒤 **동적 콘텐츠 삽입**을 고릅니다. 목록에서 트리거의 **사유**를 고릅니다.

    {: .warning }
    **필터 쿼리의 왼쪽은 열의 내부 이름입니다.** 화면에 보이는 열 이름과 다를 수 있습니다. 목록 설정에서 열을 눌렀을 때 주소의 `Field=` 뒤가 내부 이름입니다.[^getitems]

    **최대 개수**에 `20`을 입력합니다.

5. **항목 가져오기**와 **Respond to the agent** 사이의 **+** 를 누릅니다. **기본 제공 도구**의 **데이터 작업**을 누르고 **선택**을 고릅니다.

    **보낸 사람** 칸에 `/` 를 입력하고 **동적 콘텐츠 삽입**에서 **항목 가져오기**의 `body/value`를 고릅니다.

    **매핑**에 다섯 줄을 만듭니다. 키는 글자로 입력하고, 값은 `/` → **동적 콘텐츠 삽입**에서 **항목 가져오기**의 열을 고릅니다.

    | 키 | 값 |
    |---|---|
    | 신청자 | `신청자` 열 |
    | 원문 | `원문` 열 |
    | 사유 | `사유` 열 |
    | 경조금 | `경조금` 열 |
    | 경조휴가 | `경조휴가` 열 |

    흐름이 에이전트에게 넘기는 칸은 이 다섯 개입니다.

6. **Respond to the agent** 노드를 누르고 **+ 출력 추가**를 누릅니다.

    **출력 유형 선택**에서 **텍스트**를 고르고 이름에 `결과`를 입력합니다. 값 칸에 `/` 를 입력하고 **식 삽입**을 고릅니다.

    아래 수식을 붙여넣고 **추가**를 누릅니다.

    ```
    string(body('선택'))
    ```

    툴바의 **초안 저장**을 누른 뒤 **게시**를 누릅니다.

## 단계 ② 에이전트 연결과 테스트

7. 왼쪽 탐색의 **에이전트**를 눌러 복리후생 안내 도우미로 돌아갑니다.

    상단 **도구** 탭에서 **+ 도구 추가**를 누르고, **흐름** 탭에서 `경조 신청 사유별 조회 HGD`를 고른 뒤 **추가 및 구성**을 누릅니다.

8. **세부 정보**의 **설명**을 아래로 바꾸고 오른쪽 위 **저장**을 누릅니다.

    ```
    경조사 신청 기록을 사유별로 조회한다. 사유는 "본인 결혼", "자녀 결혼", "배우자 출산", "본인·배우자 부모상", "조부모·형제자매상", "규정 없음" 중 하나로 넣는다.
    ```

9. 상단 **도구** 탭에서 `경조 신청 조회`의 **사용 설정됨** 토글을 끕니다.

    상단 **개요** 탭에서 **지침**의 **편집**을 누릅니다. `[경조사 신청 처리]` 블록 마지막 줄의 `경조 신청 조회` 칩을 지우고, **`/`** 를 입력해 목록에서 `경조 신청 사유별 조회 HGD`를 고릅니다. 칩으로 바뀐 뒤 **저장**을 누릅니다.

    ```
    - 경조사 신청 내역을 묻는 요청은 /경조 신청 사유별 조회 HGD 도구로 조회한다.
    ```

10. **새 테스트 세션**에서 물어봅니다.

    ```
    규정 없음으로 들어온 경조 신청 보여줘
    ```

11. 표현을 바꿔 물어봅니다.

    ```
    외할머니 돌아가신 건 신청 들어온 거 있어?
    ```

    외할머니 상은 사유 `조부모·형제자매상`에 해당합니다.
