# 피날레 — 회고 🎬

> **이번 랩 완성물**: 없음(회고) — 오늘 한 것과 안 한 것의 경계 정리
> **예상 시간**: 10분 · **완성 신호**: 맡겨도 되는 자리와 정해 둬야 하는 자리를 각각 하나씩 들 수 있다

{: .time }
10분 타이머.

## 오늘 만든 것

에이전트 둘과 도구 다섯입니다.

| 만든 것 | 어디서 | 무엇이 붙었나 |
|---|---|---|
| 메일 요약 보조 | [Lab 1](./lab1.html) | 지침 + 가드레일 |
| 복리후생 안내 도우미 | [Lab 2](./lab2.html)~[Lab 6](./lab6.html) | 지식 4종 · 웹사이트 · 토픽 2개 · 커넥터 3개 · 흐름 1개 · MCP |

도구 다섯 중 셋은 가져다 썼고, 하나는 만들었고, 하나는 데려왔습니다.

## 어디까지 맡기고 어디부터 정하는가

랩마다 같은 질문이 돌아왔습니다.

| | 맡길 때 | 정해 둘 때 |
|---|---|---|
| 답의 근거 | 지어내기도 한다 ([Lab 2](./lab2.html) 부록) | 문서를 주면 근거가 붙는다 ([Lab 2](./lab2.html)) |
| 대화의 흐름 | 같은 질문에 답이 갈린다 ([Lab 4](./lab4.html) 11번) | 토픽은 그린 대로 흐른다 ([Lab 4](./lab4.html)) |
| 읽어 오는 양 | 표를 통째로 가져온다 ([Lab 5](./lab5.html) 11번) | 필터로 한 줄만 ([Lab 6](./lab6.html) 14번) |
| 쓰는 자리 | 값이 밀려 들어간다 ([Lab 5](./lab5.html) 24번) | 칸마다 이어 둔 대로 ([Lab 6](./lab6.html) 21번) |

{: .important }
**무조건 정해 두는 것이 답은 아닙니다.** [Lab 4](./lab4.html) 32번에서 오케스트레이터가 입력 변수를 채우고·유지하고·비우는 것을 봤습니다. 맡겨서 잘 되는 자리가 있고 아닌 자리가 있습니다. 어느 쪽인지 아는 것이 오늘의 결과물입니다.

## 오늘 배운 것

**설명이 판단 근거다.** 오케스트레이터가 지식·토픽·도구·에이전트 중 무엇을 쓸지 고르는 기준은 언제나 설명이었습니다. [Lab 2](./lab2.html) 16번의 문서별 설명, [Lab 4](./lab4.html) 4번의 토픽 작업 설명, [Lab 5](./lab5.html) 7번의 도구 설명, [Lab 6](./lab6.html) 33번의 MCP 도구 설명까지 여섯 번 나왔습니다.

**지식은 기준이지 데이터가 아니다.** 제도는 알지만 내 잔여 연차는 모릅니다([Lab 2](./lab2.html)). 이 경계를 지키는 것이 Lab 2의 전부였습니다.

**근거처럼 보이는 것과 실제 근거는 다르다.** [Lab 2](./lab2.html) 부록에서 없는 문서 이름이 근거로 붙었고, [Lab 3](./lab3.html) 16번에서 눌러서 원문을 확인했고, [Lab 5](./lab5.html) 9번에서 도구가 실제로 불렸는지를 봤습니다.

**커넥터는 손이다.** 지식이 「무엇을 아는가」라면 커넥터는 「무엇을 할 수 있는가」입니다([Lab 5](./lab5.html)). 붙인 도구가 곧 능력의 경계이고, 그 경계 안쪽은 열려 있습니다.

**지침은 부탁이고 절차는 강제다.** [Lab 1](./lab1.html)에서 지침이 안 지켜지는 것을 봤고, [Lab 6](./lab6.html)에서 흐름으로 조건과 순서를 정해 두었습니다.

**길이는 곧 비용이다.** 토큰과 [Copilot Credit](./glossary.html#copilot-credit)의 관계는 [부록 「에이전트 안에서 일어나는 일」](./appendix/inside-the-agent.html)에 있습니다.

## 오늘 안 한 것

[Lab 6](./lab6.html) 29번에서 흐름을 붙인 뒤에도 다섯 건은 그대로 들어갔습니다. 달라진 것은 한 건씩, 검증을 거쳐, 정해진 자리에 들어간다는 것뿐이었습니다.

{: .important }
**흐름은 일어날 일을 좁히는 도구이지 못 하게 막는 도구가 아닙니다.** 막는 것과 묻는 것은 여기서부터입니다.

- **사람 승인**([HITL](./glossary.html#hitl)) — 실행 전에 사람에게 물어보고, 답을 받고 나서 진행하는 것
- **여러 건 처리** — 한 번에 여러 건을 받아 처리하고, 중간에 실패하면 앞의 것을 어떻게 할지 정하는 것
- **사람 없이 도는 흐름** — 오늘 트리거는 「에이전트가 호출하는 경우」 하나였습니다. 메일 수신이나 일정으로도 시작할 수 있습니다
- **남이 쓰게 하는 것** — 오늘은 전부 내 테스트 창 안에서 끝났습니다. 게시하고 채널에 올리는 것은 다른 얘기입니다
