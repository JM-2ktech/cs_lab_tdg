     ★ ④ 절을 다시 짰다(2026-08-11, 사용자 실측 지적). 초안이 네 군데 틀렸다.
       1. 「메시지 노드를 텍스트 ∨ 로 적응형 카드로 바꾼다」 → 불가능하다.
          「메시지 보내기」와 「적응형 카드로 질문」은 다른 계열이고 상호 전환이
          안 된다. 카드는 **새 노드로 추가**해야 한다. 5번의 「텍스트 ∨」 설명도
          같이 지웠다(그 드롭다운이 무엇인지는 미확인).
       2. 카드 노드의 정식 이름은 **「적응형 카드로 질문」**이고 질문 계열이다.
          17번 「질문하기」와 같은 갈래. 다만 입력 요소를 두지 않으면 표시만 한다.
          실무에서는 예/아니오 확인에 많이 쓰인다.
       3. ⚠️ **적응형 카드는 슬롯 필링이 안 된다.** 25~27번은 「질문하기」 전용이다.
       4. ⚠️ **JSON에서 `${변수}` 를 쓰면 글자 그대로 찍힌다.** 초안의 "변수 연결
          기능" 스텝은 존재하지 않는 기능이었다.
          → 실측 경로: 노드 속성의 **형식** 드롭다운이 `JSON` / `수식` 둘이다.
            JSON으로 틀을 붙여넣고 → 형식을 수식으로 바꾸면 내용이 옮겨진다 →
            값 두 칸만 직접 고쳐 쓴다. 지우고 다시 쓰는 것이 아니다.
          → 수식 쪽에는 `{x}` 버튼이 없다. `Topic.` 접두사를 직접 쓴다.
          → ⚠️ **`문의유형`은 `Text()` 로 감싸야 한다.** choice 형식이라 카드의
            value(문자열)에 그대로 못 넣는다. `담당부서`는 string이라 그대로.
            22번에서 본 `choice`/`string` 표시가 여기서 쓸모를 낸다.
          → ⚠️ 내가 "변수는 문자열 밖에 놓고 `&` 로 잇는다"고 쓴 것은 틀렸다.
            그건 TextBlock에서 리터럴과 문자열을 결합할 때 쓰는 방식이고 여기엔
            해당 없다. 기억이 교차된 것. 삭제했다.
       - 「적응형 카드 편집」은 디자이너 한 화면이다. 왼쪽 요소 팔레트 / 가운데
         카드 구조 트리 / 아래 **카드 페이로드 편집기**(JSON)가 같이 있다.
         초안의 "JSON 보기와 UI 편집을 오간다"는 틀렸다 — 한 화면에 다 있다.

    ```
    문의유형은 "복지포인트", "휴가·근태", "경조사" 중 하나로 처리한다.
    ```

    **완료 기준**: 설명에 값의 목록이 들어갔다. 저장합니다.

    ![작업 설명에 값 목록을 더한 상태](../assets/lab2/lab2-26.png)

27. **새 테스트 세션**에서 값을 **질문에 미리 담아** 물어봅니다.

    ```
    복지포인트 담당자 알려줘
    ```

    **완료 기준**: **선택지가 뜨지 않습니다.** 질문을 건너뛰고 바로 `복지포인트 담당자를 안내해 드리겠습니다.` 가 나온다.

    ![질문을 건너뛰고 바로 답한 화면](../assets/lab2/lab2-27.png)

    <details markdown="block">
    <summary>질문을 건너뛴 이유</summary>

    25번에서 읽은 「변수가 비어 있을 경우」가 이것입니다. 오케스트레이터가 값을 미리 채웠으므로 질문 노드는 묻지 않고 지나갑니다. 값이 비어 있으면 묻습니다.

    설명 칸은 4번에서 이 토픽을 언제 부를지 정했고, 26번에서는 무엇을 채울지 알려 줍니다.

    </details>

    이것을 슬롯 필링이라고 부릅니다. 사용자가 이미 말한 값은 다시 묻지 않으므로 그만큼 대화가 짧아집니다.

## 역할
