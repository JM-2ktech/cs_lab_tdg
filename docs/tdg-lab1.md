## 단계 ① 에이전트를 만든다

1. [copilotstudio.microsoft.com](https://copilotstudio.microsoft.com)에 본인 M365 계정으로 로그인합니다.

    ![Copilot Studio 홈 화면](../assets/tdg1/1.png)

    홈 화면이 위와 다르면 오른쪽 위 **새로운 환경** 토글을 끕니다.

    ![새로운 환경 토글이 켜진 홈 화면](../assets/tdg1/1-2.png)

    피드백 창이 뜨면 **제출**을 누릅니다.

    ![새로운 환경을 끌 때 뜨는 피드백 창](../assets/tdg1/1-3.png)

2. 상단 가운데 **환경**이 강사가 안내한 환경인지 확인합니다.

    ![상단 가운데의 환경 표시](../assets/tdg1/2.png)

3. 왼쪽 메뉴 **에이전트**에서 **+ 빈 에이전트 만들기**를 누릅니다.

    ![에이전트 메뉴와 빈 에이전트 만들기 버튼](../assets/tdg1/3.png)

4. **에이전트 이름 지정** 창에서 **에이전트 설정(선택 사항)**을 펼칩니다.

    ![에이전트 이름 지정 창의 에이전트 설정(선택 사항)](../assets/tdg1/4.png)

5. 이름 칸과 **스키마 이름** 접두사 뒤에 아래를 입력하고 **만들기**를 누릅니다. `HGD` 대신 본인 영문 이니셜을 넣고, **언어**와 **솔루션**은 기본값 그대로 둡니다.

    ```
    복리후생 안내 도우미 HGD
    ```

    ```
    WelfareAgentHGD
    ```

    {: .warning }
    **이름 끝에 본인 이니셜을 넣습니다.** 교육생 전원이 같은 환경에서 작업하므로, 이름이 같으면 목록에서 본인 에이전트를 고를 수 없습니다.

    ![이름과 스키마 이름을 입력한 에이전트 이름 지정 창](../assets/tdg1/5.png)

    **만들기**를 누르면 **준비 중** 화면이 뜹니다.

    ![에이전트를 만드는 동안 뜨는 준비 중 화면](../assets/tdg1/5-2.png)

6. **여러분의 에이전트이(가) 프로비전되었습니다** 메시지가 뜨면 **세부 정보**의 **편집**을 누릅니다. 메시지가 뜨기 전에는 편집이 활성화되지 않습니다.

    ![프로비전 완료 메시지와 세부 정보의 편집 버튼](../assets/tdg1/6.png)

    **설명**에 아래를 입력하고 **저장**을 누릅니다.

    ```
    한별소프트의 복리후생·휴가·경조사 제도를 사내 문서에 근거해 안내합니다.
    ```

    ![설명을 입력한 세부 정보와 저장 버튼](../assets/tdg1/6-2.png)

    ```
  원문: 경조 내용 그대로
  사유: 위에서 판단한 사유
  발생일: 경조 날짜를 yyyy-MM-dd 형식으로
  경조금: 원 단위 숫자만
  경조휴가: 일 단위 숫자만
  근거: 문서 이름
```
