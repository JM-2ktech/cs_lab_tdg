## 단계 ① 지원단가 조회 도구

1. 자기계발비 기준표 Excel 파일을 PC에 받습니다. 강사가 안내한 SharePoint 폴더에서 받아도 됩니다.

    [자기계발비_기준표.xlsx 다운로드](../assets/download/자기계발비_기준표.xlsx)

    ![SharePoint 폴더의 자기계발비_기준표.xlsx](../assets/tdg2/1.png)

2. 새 탭에서 OneDrive를 열고, **내 파일**의 **문서** 폴더에 1번 파일을 업로드합니다.

    {: .warning }
    **파일은 각자 본인 OneDrive에 업로드합니다.** 한 파일에 여러 사람이 동시에 쓰면 병합 충돌과 데이터 불일치가 생길 수 있습니다.[^excel]

    ![OneDrive 문서 폴더에 올린 자기계발비_기준표.xlsx](../assets/tdg2/2.png)

    파일에는 표가 셋 있습니다. `지원기준`은 읽기만 하고, `신청내역`에 씁니다. `지원대상목록`은 1,000행입니다.

3. Copilot Studio 탭으로 돌아가 상단 **도구** 탭에서 **+ 도구 추가**를 누릅니다.

    ![도구 탭의 도구 추가 버튼](../assets/tdg2/3.png)

    **커넥터** 탭에서 **Excel Online(Business)** 를 누릅니다.

    ![도구 추가 창의 커넥터 탭과 Excel Online(Business)](../assets/tdg2/3-2.png)

    **테이블에 있는 행 나열**을 고릅니다.

    ![Excel Online(Business) 작업 목록의 테이블에 있는 행 나열](../assets/tdg2/3-3.png)

    **연결**에 본인 계정과 초록 확인 표시가 있는지 봅니다. 없으면 드롭다운에서 연결을 새로 만든 뒤 **추가 및 구성**을 누릅니다.

    ![연결 확인과 추가 및 구성 버튼](../assets/tdg2/3-4.png)

4. **세부 정보**의 **이름**과 **설명**을 아래로 바꿉니다.

    ```
    지원단가 조회
    ```

    ```
    자기계발비 항목별 지원단가를 조회한다. 항목명·지원단가·증빙서류·적용일이 들어 있는 기준표를 읽는다.
    ```

    ![이름과 설명을 바꾼 세부 정보](../assets/tdg2/4.png)

5. **입력** 네 칸을 아래 순서로 채웁니다.

    | 입력 이름 | 채우는 방법 | 값 |
    |---|---|---|
    | Location | 사용자 지정 값 | OneDrive for Business |
    | Document Library | 사용자 지정 값 | 문서 |
    | File | 사용자 지정 값 | 폴더 아이콘 › 문서 › `자기계발비_기준표.xlsx` |
    | Table | **사용자 지정 값**으로 바꾼 뒤 | `지원기준` |

    **Location**에서 **OneDrive for Business**를 고릅니다.

    ![Location 목록의 OneDrive for Business](../assets/tdg2/5.png)

    **Document Library** 목록이 비어 있으면 **새로 고침**을 누르고, **문서**를 고릅니다.

    ![Document Library 목록의 새로 고침](../assets/tdg2/5-2.png)

    ![Document Library 목록의 문서](../assets/tdg2/5-3.png)

    **File**의 폴더 아이콘을 눌러 **문서** 옆 **>** 로 들어가 `자기계발비_기준표.xlsx`를 고릅니다.

    ![File 폴더 목록의 문서](../assets/tdg2/5-4.png)

    ![문서 폴더의 자기계발비_기준표.xlsx](../assets/tdg2/5-5.png)

    **Table**의 채우는 방법을 **사용자 지정 값**으로 바꾸고 `지원기준`을 고릅니다.

    {: .warning }
    **`Table`의 기본값은 「AI로 동적으로 채우기」입니다.** 그대로 두면 어느 표를 읽을지 오케스트레이터가 호출마다 정하고, `신청내역`을 읽고 지원단가를 답할 수 있습니다.

    ![네 입력을 채운 화면](../assets/tdg2/5-6.png)

6. **세부 정보** 아래 **추가 세부 정보**를 펼칩니다.

    ![추가 세부 정보](../assets/tdg2/6.png)

    **사용할 자격 증명**을 **작성자가 제공한 자격 증명**으로 바꿉니다.

    ![사용할 자격 증명 목록의 작성자가 제공한 자격 증명](../assets/tdg2/6-2.png)

7. 오른쪽 위 **저장**을 누른 뒤, 테스트 창의 **새 테스트 세션**을 누르고 물어봅니다.

    ```
    어학시험 응시료 지원단가가 얼마야?
    ```

    ![지원단가 조회가 완료로 기록된 활동과 답변](../assets/tdg2/7.png)

    답은 `지원기준` 표에서 읽어 온 값입니다.

## 단계 ② 신청내역 기록 도구

8. **지침** 맨 아래에 아래 블록을 붙여넣습니다.

    ```
    [자기계발비 신청 처리]
    - 사용자가 자기계발비 신청을 요청하면 항목명과 수량을 확인한다. 둘 중 빠진 것이 있으면 먼저 되묻는다.
    - 지원단가는 /지원단가 조회 도구로 조회한다.
    - 금액은 지원단가 곱하기 수량으로 계산한다.
    - 처리 결과는 아래 형식으로 통보한다.

      [자기계발비 신청 접수]
      항목: 항목명
      지원단가: 지원단가원 곱하기 수량건
      금액: 금액원
      상태: 접수
    ```

    {: .warning }
    붙여넣을 때 `-` 로 시작하는 줄과 대괄호는 그대로 두고, **숫자 목록이나 `*` 는 쓰지 않습니다.** 이 칸은 붙여넣은 글을 마크다운으로 해석합니다.

    `/지원단가 조회` 글자를 지우고 **`/`** 를 입력해 목록에서 `지원단가 조회` 도구를 고릅니다. 도구 이름이 칩으로 바뀐 뒤 **저장**을 누릅니다.

    ![지원단가 조회 칩이 들어간 지침](../assets/tdg2/8.png)

9. **새 테스트 세션**에서 신청합니다.

    ```
    도서구입으로 4건 자기계발비 신청할게요
    ```

    ![지원단가 조회가 완료로 기록된 신청 답변](../assets/tdg2/9.png)

10. **활동** 탭에서 9번 대화를 엽니다. **추론** 칸에 지원단가와 수량을 곱한 계산이 문장으로 남아 있습니다.

    ![활동 탭의 추론 칸](../assets/tdg2/10.png)

11. 상단 **도구** 탭에서 **+ 도구 추가**를 누르고, **커넥터** 탭에서 **Excel Online(Business)** 를 누릅니다. **테이블에 행 추가**를 고릅니다.

    ![Excel Online(Business) 작업 목록의 테이블에 행 추가](../assets/tdg2/11.png)

    **연결**에 본인 계정과 초록 확인 표시가 있는지 본 뒤 **추가 및 구성**을 누릅니다.

12. **세부 정보**의 **이름**과 **설명**을 아래로 바꿉니다.

    ```
    신청내역 기록
    ```

    ```
    자기계발비 신청 내역을 신청내역 표에 기록한다. 신청자·항목명·수량·금액·상태를 한 행으로 추가한다.
    ```

    ![이름과 설명을 바꾼 세부 정보](../assets/tdg2/12.png)

13. **입력** 네 칸을 아래 순서로 채웁니다.

    | 입력 이름 | 채우는 방법 | 값 |
    |---|---|---|
    | Location | 사용자 지정 값 | OneDrive for Business |
    | Document Library | 사용자 지정 값 | 문서 |
    | File | 사용자 지정 값 | 폴더 아이콘 › 문서 › `자기계발비_기준표.xlsx` |
    | Table | **사용자 지정 값**으로 바꾼 뒤 | `신청내역` |

    {: .warning }
    **테이블을 잘못 고르면 `지원기준`에 신청 내역이 쌓입니다.** `Table`이 `신청내역`인지 확인합니다.

    ![Table을 신청내역으로 채운 입력](../assets/tdg2/13.png)

14. **세부 정보** 아래 **추가 세부 정보**를 펼치고 **사용할 자격 증명**을 **작성자가 제공한 자격 증명**으로 바꿉니다. 오른쪽 위 **저장**을 누릅니다.

    ![작성자가 제공한 자격 증명과 저장](../assets/tdg2/14.png)

15. **새 테스트 세션**에서 신청하고 기록까지 시킵니다.

    ```
    도서구입으로 4건 자기계발비 신청하고 신청내역에 기록해줘
    ```

    답변 위의 **신청내역 기록** 활동을 누르면 **Row**에 넣은 값이 보입니다.

    ![신청내역 기록의 Row 입력과 답변](../assets/tdg2/15.png)

16. OneDrive에서 Excel 파일을 열어 `신청내역`을 봅니다.

    ![신청내역 5행에 칸이 어긋나 기록된 값](../assets/tdg2/16.png)

    어느 값이 어느 칸에 들어갈지는 도구에 정해 두지 않았습니다. 「테이블에 행 추가」 도구에는 칸마다 값을 지정하는 입력이 없고 대상 테이블만 고릅니다.

17. **새 테스트 세션**에서 여러 건을 한 번에 시킵니다.

    ```
    다섯 항목을 각 1건씩 전부 신청하고 기록해줘
    ```

    ![신청내역 기록이 다섯 번 호출된 활동과 답변](../assets/tdg2/17.png)

    요청을 보낸 뒤 Excel의 `신청내역`을 다시 엽니다.

    ![다섯 행이 같은 방식으로 어긋난 신청내역](../assets/tdg2/17-2.png)

## 단계 ③ 자기계발비 신청 처리 흐름

18. 상단 **도구** 탭에서 **+ 도구 추가**를 누르고, 위쪽 **새로 만들기**에서 **에이전트 흐름**을 고릅니다.

    ![도구 추가의 새로 만들기 › 에이전트 흐름](../assets/tdg2/18.png)

19. 툴바의 **초안 저장**을 먼저 누르고, 좌측 상단 이름을 아래로 바꿉니다. `HGD` 대신 본인 이니셜을 넣습니다.

    ```
    자기계발비 신청 처리 HGD
    ```

    {: .warning }
    **이름부터 바꾸면 저장되지 않습니다.**

    ![초안 저장 후 바꾼 흐름 이름](../assets/tdg2/19.png)

20. 캔버스의 **manual** 노드를 누릅니다. 흐름의 첫 노드인 트리거이고, 왼쪽에 설정 창이 열립니다.

    ![manual 트리거 노드와 설정 창](../assets/tdg2/20.png)

21. 트리거의 **매개 변수** 탭에서 **+ 입력 추가**를 누릅니다.

    ![매개 변수 탭의 입력 추가](../assets/tdg2/21.png)

    형식을 고르고 이름과 설명을 입력합니다. 같은 방법으로 입력 세 개를 만듭니다.

    | 형식 | 이름 | 설명 |
    |---|---|---|
    | 텍스트 | `항목명` | `항목명을 입력하세요` |
    | 숫자 | `수량` | `항목의 수량을 입력하세요` |
    | 이메일 | `이메일` | `흐름을 호출한 사용자의 이메일을 입력하세요` |

    ![항목명 입력의 이름과 설명](../assets/tdg2/21-2.png)

    **익스프레스 모드**를 켭니다.

    ![입력 세 개와 켠 익스프레스 모드](../assets/tdg2/21-3.png)

22. 트리거와 **Respond to the agent** 사이의 **+** 를 누릅니다.

    ![manual과 Respond to the agent 사이의 +](../assets/tdg2/22.png)

    **작업 추가**의 **커넥터별**에서 **Excel Online(Business)** 를 누릅니다.

    ![작업 추가의 Excel Online(Business)](../assets/tdg2/22-2.png)

    **테이블에 있는 행 나열**을 고릅니다.

    ![Excel Online(Business) 작업 목록의 테이블에 있는 행 나열](../assets/tdg2/22-3.png)

    매개 변수 네 칸을 채웁니다.

    | 매개 변수 | 값 |
    |---|---|
    | 위치 | OneDrive for Business |

```
- 개인의 실제 데이터(내 잔여 연차, 내 별포인트 잔액, 내 급여)는 알 수 없다. 숫자를 추정하지 말고 "한별포털에서 확인하거나 피플팀(내선 1000)으로 문의해 주세요"라고 안내한다.
- 문서에 없는 내용은 지어내지 않는다. "제공된 문서에서 찾을 수 없습니다"라고 답한다.
- 규정의 해석·예외 적용 여부는 단정하지 않는다. 판단이 필요한 사안은 피플팀 확인으로 넘긴다.

[경조사 신청 처리]
- 사용자가 경조사 신청을 요청하면 신청자 이름, 경조 날짜, 경조 내용을 확인한다. 빠진 것이 있으면 먼저 되묻는다.
- 경조 내용을 읽고 사유를 판단한다. 사유는 아래 여섯 가지 중 하나로만 적는다.
  본인 결혼 / 자녀 결혼 / 배우자 출산 / 본인·배우자 부모상 / 조부모·형제자매상 / 규정 없음
- 경조금과 경조휴가는 경조사·생활지원 문서의 표에 적힌 값을 쓴다. 규정 없음이면 둘 다 0으로 적는다.
- /경조 신청 기록 도구로 한 항목을 추가한다. 열에는 아래 값을 넣는다.
  제목: 신청자와 사유
  신청자: 신청자 이름
  원문: 경조 내용 그대로
  사유: 위에서 판단한 사유
  발생일: 경조 날짜를 yyyy-MM-dd 형식으로
  경조금: 원 단위 숫자만
  경조휴가: 일 단위 숫자만
  근거: 문서 이름
- 경조사 신청 내역을 묻는 요청은 /경조 신청 조회 도구로 조회한다.

[자기계발비 신청 처리]
- 사용자가 자기계발비 신청을 요청하면 항목명과 수량을 확인한다. 둘 중 빠진 것이 있으면 먼저 되묻는다.
- 지원단가는 /지원단가 조회 도구로 조회한다.
- 금액은 지원단가 곱하기 수량으로 계산한다.
- 처리 결과는 아래 형식으로 통보한다.

  [자기계발비 신청 접수]
  항목: 항목명
  지원단가: 지원단가원 곱하기 수량건
  금액: 금액원
  상태: 접수
```

`/System.User.Email`·`/자기계발비 신청 처리 HGD`·`/지원단가 조회`·`/경조 신청 기록`·`/경조 신청 조회`는 화면에서 **칩**입니다. 통째로 붙여넣으면 글자가 되므로, 그 줄만 `/` 를 다시 입력해 목록에서 고릅니다.
